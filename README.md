# ViralPost

Gerador de carrosséis virais com IA para Instagram.

## Setup local

```bash
npm install
npm start
```

Acesse `http://localhost:3000`

## Variáveis de ambiente

| Variável | Descrição |
|----------|-----------|
| `AIBEE_API_KEY` | Chave da API Aibee Cloud |
| `AIBEE_BASE_URL` | URL base da API (ex: https://api.aibee.cloud) |
| `AIBEE_MODEL` | Modelo a usar (ex: gpt-4) |
| `PORT` | Porta do servidor (padrão: 3000) |
